Physics Arcade: Projectile Challenge

An interactive physics-based projectile motion simulator and mini-game built using HTML, CSS, and JavaScript for a college physics project.

## Live Demo

[https://marouf-jk.github.io/projectile/](https://marouf-jk.github.io/projectileGame/)

---

Features

* Real-time projectile motion simulation
* Adjustable launch angle, speed, and gravity
* Multiple difficulty levels
* Moving targets in expert mode
* Prediction challenge system
* Replay last shot feature
* Live physics graph visualization
* Physics formulas and breakdown panel
* Player progress saving using localStorage
* Responsive UI design

---

Technologies Used

* HTML5
